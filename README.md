# Gillette Shop — интернет‑магазин original товаров для бритья (Germany)

## Описание проекта

Pet‑проект интернет‑магазина товаров для бритья (в фокусе - продукция Gillette). Реализуется на Django как витрина с каталогом, фильтрацией и пагинацией, с перспективой расширения до полноценного магазина с корзиной, личным кабинетом и оформлением заказов.

**Цель:** Django‑стек и жизненного цикла веб‑приложения:
от моделей и ORM до шаблонов, маршрутизации и работы с данными. Проект спроектирован так, чтобы его можно было поэтапно развивать без переписывания архитектуры.

**Стек:** Python, Django 6.1.1, SQLite (с планом миграции на PostgreSQL), Bootstrap 5.

## Текущее состояние (реализовано)

### Ядро и структура

- Создан Django‑проект `app1` и приложения `main` (основные страницы) и `goods` (каталог и товары).
- Реализована архитектура MTV: модели описывают данные, представления обрабатывают логику, шаблоны отвечают за отображение.
- Настроена базовая маршрутизация с пространствами имён (`namespace`) и подключением приложений через `include`.

### Модели и данные

- Разработаны модели `Categories` и `Products` с необходимыми полями: название, slug, описание, цена, скидка, изображение, категория.
- Реализованы вспомогательные методы в модели `Products`:
  - `display_id()` — форматированный ID товара.
  - `sell_price()` — расчёт цены со скидкой.
- База данных инициализирована миграциями, начальные данные загружены через fixtures (JSON).
- Настроена админка: модели зарегистрированы, для полей с названиями настроена автоматическая генерация `slug`.

### Каталог и отображение

- Реализован вывод каталога товаров через цикл в шаблоне, карточки товаров содержат фото, цену, скидку и описание.
- Поддерживается переход к товару по `id` и по читаемому `slug` (URL‑конвертеры).
- Внедрена пагинация: товары выводятся постранично, при переключении страниц сохраняются активные фильтры и сортировка.
- Реализована фильтрация по признаку "товары по акции" и сортировка по цене.

### Шаблоны, статика и медиа

- Базовый шаблон `base.html` с наследованием и блоками для переопределения содержимого.
- Корректная работа со статикой (CSS, JS, иконки) через тег `{% load static %}` и настройку `STATIC_URL`.
- Обработка медиа‑файлов: изображения товаров хранятся в `media/`, предусмотрена заглушка для отсутствующих фото.

## Установка и запуск

1. **Клонирование и окружение:**
   ```bash
   git clone <адрес-репозитория>
   cd app1

   python3 -m venv venv
   # macOS/Linux:
   source venv/bin/activate
   # Windows:
   venv\Scripts\activate

2. **Установка зависимостей:**

    ```bash
    pip install Django==6.1.1 django-debug-toolbar

3. **Миграции и загрузка данных:**

    ```bash
    python3 manage.py migrate

    python3 manage.py loaddata fixtures/categories.json
    python3 manage.py loaddata fixtures/products.json

4. **Создание суперпользователя:**

    ```bash
    python3 manage.py createsuperuser

5. Запуск сервера:

    ```bash
    python3 manage.py runserver

    Админка: http://127.0.0.1:8000/admin/
